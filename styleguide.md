# Dina's Allure — Brand Style Guide

**Brand Guidelines · v1.0**

A quick reference for keeping every page, post, and product photo consistent with the Dina's Allure look: organic, honest, and quietly feminine — never generic "clean beauty," never loud.

---

## Logo

**Primary logo:** the full "Dina's Allure" wordmark in Allure Pink, with the face-and-petal icon built into the "D."

**Icon mark:** the face-and-petal symbol alone (cropped from the "D"), used for favicons, social avatars, or any space too tight for the full wordmark.

**On dark backgrounds:** the wordmark reproduces in solid white.

### Do
- Keep clear space around the logo equal to the height of the "D"
- Use the full wordmark for headers and packaging
- Use the icon mark alone only for favicons, social avatars, or tight spaces

### Don't
- Recolor the logo outside pink, plum, white, or black
- Stretch, rotate, or add drop shadows to the wordmark
- Place it on busy photography without a solid or blurred backing

## Color Palette

Pulled directly from the logo pink, extended with a deep plum for contrast and a warm ivory/blush pair for backgrounds. Gold is an accent only — never a base color.

| Color | Hex | Usage |
|---|---|---|
| Allure Pink | `#F0509D` | Primary brand color |
| Pink Deep | `#D63C86` | Hover / pressed states |
| Plum | `#6E1E42` | Dark sections, footer |

## Buttons & Tags

- **Primary button:** filled Allure Pink, white text, fully rounded pill shape. Example: "Shop the Collection"
- **Outline button:** transparent fill, plum text, 1.5px pink border. Pairs with a primary action as the secondary option. Example: "Our Story"
- **Small button:** same pill style, smaller padding. Example: "Add to Bag"
- **Tag / chip:** blush background, pink-deep text, small bold uppercase label, fully rounded. Example: "LIP GLOSS"

Never use square-cornered buttons — the pill shape is consistent everywhere.

---

## Form Fields

- 12px corner radius
- Thin blush-toned border
- Pink focus ring on active/focus state
- Labels are small, bold, and muted (color `#7A5A66`) — never placeholder-only

---

## Cards

Three card types, all sharing the same base style:

1. **Product card** — color swatch circle, name, one-line description, price + action button
2. **Value card** — numbered (e.g. "01 — Organic First"), used for brand pillars and principles
3. **Testimonial card** — star rating, italic quote, customer name

**Shared card style:** 20px corner radius, 1px blush-line border, white or ivory fill, lifts 6px on hover with a soft plum-tinted shadow — never a plain grey shadow.

---

## Iconography

Outline style only, 1.8px stroke, no fill, rounded joins. Icons sit inside a blush-pink circular badge at 52–64px.

Example icon set: shea drop, oil, botanical/sparkle, shopping bag.

Never mix in solid/filled icon styles.

---

## Spacing & Radius Quick Reference

| Token | Value | Used for |
|---|---|---|
| Radius — pill | `999px` | Buttons, tags, filter chips |
| Radius — card | `20–24px` | Product, value, form cards |
| Radius — icon badge | `12–16px` / `50%` | Icon containers |
| Section padding | `100px` vertical | Desktop page sections |
| Grid gap | `24–30px` | Product & feature grids |

## Voice & Tone

### We sound like
- A friend who reads ingredient labels for you
- Warm, plain-spoken, a little poetic — never clinical
- Confident about quality without over-claiming certifications

### We never sound like
- A lab report or a legal disclaimer
- Aggressive sales copy ("BUY NOW!!")
- Generic wellness-speak with no specifics
